¿Por qué realizar este curso?

Aprende a utilizar R y RStudio para analizar datos científicos de forma práctica, desde la importación de datos hasta la creación de gráficos y análisis estadísticos.

🎯 Objetivo

Dominar las herramientas fundamentales de RStudio aplicadas a la investigación.

🧪 Enfoque práctico

Cada clase incluye ejemplos reales, ejercicios guiados y resolución de casos.

📚 Material incluido

Recibirás diapositivas, scripts de R, bases de datos y ejercicios para practicar.
